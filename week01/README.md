# Markdown example output

The **word** will be bold. Writing `inline code` is done with backticks.

Blockquotes are done with a `>` prefix.

> This is a blockquote.

Lists are done with a `*` prefix.

* Item 1
* Item 2
* Item 3

Images are done with a `!` prefix.

![Alt text](img/placeholder.jpg)

Links are done with a `[]` prefix.

[A link to Google][url]

[url]: https://www.google.com
